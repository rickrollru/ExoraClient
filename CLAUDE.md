## Что делаем
Свой клиент для DDNet (DDraceNetwork) с полностью новым современным визуалом в стиле
Minecraft-клиентов (Nursultan, Expensive, Space Visuals): красивое меню, новый HUD и куча
визуальных эффектов.

- **База:** форк TClient (https://github.com/sjrc6/TaterClient-ddnet). Лицензия zlib, как у DDNet:
  форкать можно, но изменённая версия должна быть явно помечена как изменённая.
- **«Каша»:** потом переносим ЛЕГАЛЬНЫЕ фичи из других форков (Cactus, Meow, BestClient и др.),
  проверяя их лицензии.
- **Жёсткое правило:** никаких читов — никаких ботов, автохука, авто-фейза, ESP и т.п.
  Только визуал, HUD, удобство (QoL).
- Пока клиент для себя, не для публичного релиза.

## Решения по дизайну
Структуру берём с референсов (Expensive redesign, Space Visuals), цвета свои.

- **Всё меню целиком** заменяет стандартное (по Esc), не отдельное окно поверх.
- **Навигация:** верхний бар — капсула с иконками-вкладками по центру, лого слева, справа поиск/язык/тема/аватар.
- **Разделы:** Главная, Серверы, Визуалы, Конфиги, Настройки (+ Демки позже).
- **Компоновка:** контент слева + панель деталей справа.
- **Карточки настроек как в Space Visuals:** inline-карточки в 2 колонки; шапка = название + серое
  описание + плашка бинда + тогл; под разделителем все параметры сразу (без правого клика и вложенных окон).
  Для 2–4 вариантов — segmented control, не дропдаун. Слайдер на всю ширину: название слева, число справа.
- **Типографика:** без КАПСА. Три уровня: жирный заголовок, серое описание, средне-серые названия параметров.
  Основной шрифт геометрический (Manrope), в настройках выбор: Manrope / Onest / Unbounded.
- **Темы:** тёмная и светлая + выбор акцента: голубой #4F8CFF, мятный #3DD6A4, оранжевый #FF8A3D,
  розовый #FF5C8A, лаймовый #B6E83C, красный #FF4D4D, белый (монохром). Дефолт выберем позже.
- **Тёмная тема:** фон #0A0B0E, панели rgba(17,19,24,0.82), карточки rgba(28,31,38,0.9),
  обводка 1px rgba(255,255,255,0.07), текст #F2F3F5, вторичный #C9CCD2, приглушённый #8C919B.
- **Скругления:** окно/панели 14–18px, карточки 10–14px, мелкие плашки 6px.
- **Анимации:** уровень выбирает пользователь (вкл/выкл + пресеты).
- **Фон меню:** выбор пользователя — блюр поверх игры / анимированный фон / карта.
- **Язык:** RU/EN через систему переводов DDNet.
- **Масштаб UI:** настройка для 1080p / 2K / 4K.
- **Производительность:** пресеты Низкое/Среднее/Высокое + ручные тоглы каждого эффекта.
- **Звуки интерфейса:** есть, с выключателем.

### Экраны
- **Главная:** превью ти со скином, профиль (очки, ранг, карт пройдено), друзья онлайн, новости DDNet,
  обновление клиента, кнопка «Играть».
- **Серверы:** карточки серверов (не таблица) + фильтры (Все/Novice/Moderate/Brutal/Insane/Избранное) +
  поиск; справа панель: карта, игроки, пинг, «Войти», в избранное.
- **Конфиги:** локальные конфиги карточками + импорт/экспорт коротким кодом; справа детали
  (сохранить/загрузить/переименовать/удалить, дата, код). Без облака.
- **Настройки:** Интерфейс, Игрок, Управление, Звук, Чат, Редактор HUD.
- **HUD в игре:** переделываем весь + **редактор HUD** (перетаскивание и размер элементов).
  Ватермарка (лого, ник, FPS, пинг, время) слева сверху, тосты по центру снизу,
  красивые колёса эмоций/спектатора, ники-плашки над игроками.

### Визуалы (вкладка «Визуалы»)
Эффекты на все события; стиль выбирается в каждой карточке; в карточках выбор «Мои / Дамми / Другие».
- Погода: снег / листья / сакура / пепел, плотность, показывать в меню.
- Шлейф: линия / искры / звёзды / радуга, длина.
- Прыжки и бег: кольца / искры / звёзды при прыжке, пыль при беге, кольцо при приземлении.
- Аксессуар на ти: конус / нимб / корона.
- Хук: обычная / цветная / светящаяся линия, эффект зацепа (кольцо/искры/звёзды).
- Оружие: удар молотком, взрыв гранаты (обычный/ударная волна/неон), трассеры.
- Фриз и смерть: осколки / ледяной взрыв / пепел, эффект респавна.
- Финиш и рекорды: конфетти / салют, плашка нового рекорда, вспышка на чекпоинте и телепорте.
- «Сочность»: тряска камеры, вспышки экрана, hit-stop (только визуально) — со слайдером силы.
- Звуки событий: свои звуки на фриз/финиш/рекорд, наборы, громкость.
- Цвет мира: фильтры (тёплый/холодный/акцент), цветокоррекция.
- Идеи из MC-клиентов в 2D-варианте: China Hat, Jump Circles, Trails, Hit Particles, крылья/плащ,
  стрелки на дамми/напарника за экраном, кастомный прицел.

## Архитектура рендера (решено)
Как в MC-клиентах: НЕ заменяем движок, а встраиваемся в него.
1. **Движок DDNet** рисует игру как обычно (рендер-поток, backend OpenGL/Vulkan).
2. **Наш рендер-модуль** — хуки в рендер-потоке DDNet (после мира, перед UI, перед present).
   Работает напрямую с OpenGL: свои шейдеры, FBO, буферы. Сохраняет и восстанавливает GL-состояние.
   - post-process: Kawase/Gaussian блюр под меню, bloom/glow, цветокоррекция, виньетка
   - GPU-частицы через instancing (снег, шлейфы, искры)
   - SDF-шейдер для скруглённых прямоугольников с обводкой и тенью
3. **ImGui** (+ при необходимости **NanoVG**) рисуется нашим рендер-модулем — для всего меню и HUD.
   Инпут прокидываем из `OnInput` в `ImGuiIO`; когда меню открыто, игра инпут не получает.
- Начинаем ТОЛЬКО с **OpenGL 3.3** (на время разработки клиент запускается на нём).
  Vulkan — позже, или на нём эффекты просто выключены.
- На пресете «Низкое» тяжёлые эффекты выключаются.

## План MVP (первые 3–4 недели)
1. Поставить VS 2022 (Desktop development with C++), CMake, Git, Rust (rustup); склонировать TClient
   с `--recursive`; собрать как есть и запустить.
2. Первый видимый результат: снег поверх меню и игры с тоглом в консоли.
3. Рендер-модуль: хук в рендер-потоке, OpenGL 3.3, первый свой шейдер.
4. ImGui на нашем рендере + инпут, тестовое окно по бинду.
5. Тема и базовые виджеты: тогл, слайдер, segmented, карточка, бинд-плашка, анимации.
6. Новое меню настроек в нашем стиле вместо стандартного.
7. Пара визуалов: шлейф, кольца прыжка; блюр под меню.

Дальше: Главная → Серверы → Конфиги → Демки → HUD + редактор → все визуалы → Vulkan → фичи из форков.
