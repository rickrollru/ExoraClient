# Exora Client v0.2
**Загрузка / Download:** https://github.com/rickrollru/ExoraClient/releases/tag/v0.2

**Изменения**
- 3D-вид: мир в перспективе, объёмные блоки, режим от первого лица.
- Редактор карт: «Сделать слой 3D» — объём в карте, который видят все игроки в любом клиенте.
- Конструктор автомаппера с автоопределением ролей и вики редактора.

- Статус в Discord.
- Экраны подключения и загрузки в стиле меню, вар-лист, отключение стандартного HUD.
- Режим низкой задержки ввода, автоснижение эффектов при низком FPS.
- Исправления меню и редактора.

**Changes**
- 3D view: perspective world, solid blocks, first person mode.
- Map editor: "Make the layer 3D", depth in the map that every player sees in any client.
- Automapper builder with role detection, and an editor wiki.
- Co-op editing v2: shared tabs, playing on a local server, map changes without reloading.
- Discord status.
- Connecting and loading screens in the menu style, war list, standard HUD can be turned off.
- Low input delay mode, effects reduced automatically at low FPS.
- Menu and editor fixes.

**Установка:** распакуйте архив в любую папку и запустите DDNet.exe. Только Windows.
**Install:** extract the archive to any folder and run DDNet.exe. Windows only.

## #ru-news

# Exora Client v0.2
Вышло второе обновление. Основная тема — 3D: объёмный вид в игре и объём в картах для всех игроков.

**Подробности**
- 3D-вид: наклонная камера, объёмные блоки в цветах карты и режим от первого лица. Включается в Визуалы → Мир.
- «Сделать слой 3D» в редакторе: блоки получают боковые грани, уходящие вглубь. Это стандартный параллакс DDNet, поэтому эффект виден в любом клиенте и на любом сервере.
- Конструктор автомаппера: автомаппер для своего тайлсета собирается за несколько нажатий. Роли тайлов определяются по картинке автоматически. В редакторе появилась вики с подробными статьями.
- Совместное редактирование карт: общие вкладки, совместная игра на локальном сервере, изменения карты без перезагрузки.
- Статус в Discord, новые экраны загрузки, вар-лист в меню, режим низкой задержки ввода.

Клиент по-прежнему изменяет только отображение и удобство. Сетевая часть и физика не затронуты.

Загрузка — #client-releases

## #en-news

# Exora Client v0.2
The second update is out. Its main topic is 3D: a 3D view in the game and depth in maps for every player.

**Details**
- 3D view: tilted camera, solid blocks in the map colors and a first person mode. Turn it on in Visuals → World.
- "Make the layer 3D" in the editor: blocks get side faces that go into the depth. It uses standard DDNet parallax, so it is visible in any client and on any server.
- Automapper builder: an automapper for your own tileset takes a few clicks. Tile roles are detected from the picture automatically. The editor now has a wiki with detailed articles.
- Co-op map editing: shared tabs, playing together on a local server, map changes without reloading.
- Discord status, new loading screens, war list in the menu, low input delay mode.

The client still changes only visuals and usability. Networking and physics are untouched.

Download: #client-releases
