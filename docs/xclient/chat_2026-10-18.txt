--------------------------------------------------------------------
МАКС: Знаешь игру ddraceNetwork

CLAUDE: Да. DDNet — бесплатный кооперативный 2D-платформер, мод Teeworlds, есть в Steam.
- Играешь за круглого «ти» с хуком и оружием
- Главное — кооп: проходите карты вдвоём/командой, помогаете хуком, прыжками, молотком
- Таймер, рекорды, ранги
- Тысячи карт по сложности: Novice → Moderate → Brutal → Insane, плюс Solo, Race, Dummy
- Freeze-зоны, телепорты, свитчи, куча тех. приёмов
Спросил, играет ли Макс сам и чем помочь.

--------------------------------------------------------------------
МАКС: В курсе что есть открытый исходный код

CLAUDE: Да, репа на GitHub — ddnet/ddnet.
- C++ (плюс немного Rust), сборка через CMake
- Лицензия в основе zlib-подобная от Teeworlds: можно форкать и моддить
- В одной репе клиент, сервер и редактор карт
- Активно пилится, PR принимают
Вокруг открытого кода выросли свои клиенты, моды, тулзы.

МАКС: Знаешь про существование клиентов на эту игру?

CLAUDE: Да, два лагеря:
Легальные (фичи/удобство): TClient (Tater Client), chillerbot-ux, разные форки.
Читерские: в духе AllTheHaxx — хук-боты, авто-фейз и т.п. На офф-серверах за это банят,
а приватные «клиенты» с левых сайтов часто со стиллерами.
Готов помогать с QoL, худом, визуалом, биндами. Боты/автохук для онлайна — нет.

МАКС: Best client

CLAUDE (поиск в интернете): BestClient — кастомный клиент DDNet, форк TClient. Свой рендер,

МАКС: А курсе про Майнкрафт читы и как там выглядит имгуишка?

CLAUDE: Стиль MC-клиентов (Meteor, Wurst, LiquidBounce и др.):

--------------------------------------------------------------------
МАКС: Это реально реализовать, мы же знаем полный исходный код, можем добавить свои строки кода

CLAUDE: Да, реально. Можно встроить настоящий Dear ImGui, написав СВОЙ бэкенд поверх API DDNet:
ImGui выдаёт треугольники (ImDrawData), мы прогоняем их через Graphics(). План:
1) исходники ImGui в src/external/imgui + CMake
2) текстура шрифта через Graphics()->LoadTextureRaw
3) рендер ImDrawList через Graphics(), с clip rect
4) инпут из OnInput в ImGuiIO
5) стиль под Нурсултан через ImGuiStyle + свои виджеты
Подводные камни: координаты, блюр отдельно, обновления апстрима.

МАКС: Ещё вопрос — какой рендер мы будем использовать?

CLAUDE: Родной движок DDNet (Vulkan / OpenGL 3.3 / OpenGL 1.x). ImGui — через наш бэкенд
поверх IGraphics, частицы тоже. Сложное — настоящий блюр и свечение (нужны шейдеры).
Варианты: фейковый блюр / настоящий / сначала фейк, потом настоящий.

МАКС: Можем сделать кастомный рендер? Или найти какой-то другой?

CLAUDE: Заменить весь рендер (bgfx, Diligent, sokol, raylib) — нет смысла: рендер вшит глубоко,
каждое обновление будет ломать всё. Лучше свой «слой эффектов» в движке: игра в текстуру
(offscreen) → свои шейдеры (блюр, bloom, цветокоррекция, виньетка, аберрация) → сверху ImGui.
Сначала только OpenGL 3.3, потом Vulkan.

МАКС: Я думаю встроенный рендер может не поддерживать что я хочу, сложно оптимизировать и не
будет красивым. Можем ли не перерисовать, а как бы встроить его?

CLAUDE: Да — встраиваем свой рендер-модуль рядом с движком:
- хуки в рендер-потоке DDNet (после мира, перед UI, перед выводом)
- наш код напрямую с GPU: свои шейдеры, буферы, текстуры, сохранение/восстановление состояния
- любые эффекты, GPU-частицы через instancing, NanoVG для гладкого UI, ImGui своим рендером
- писать отдельно под OpenGL и Vulkan → стартуем с OpenGL 3.3

МАКС: А как это делают в Майнкрафте для клиентов с визуалом? Я прочитал, что используется
кастомный рендер

CLAUDE: Так же: Майнкрафт рисует через OpenGL (LWJGL); клиенты не заменяют рендер, а через
Mixin встраивают хуки и пишут прямо в OpenGL. «Кастомный рендер» у них = SDF-шейдеры
скруглений, блюр (Gaussian/Kawase во framebuffer), glow/bloom, свой рендер шрифтов (TTF/MSDF),
иногда NanoVG/Skia. У нас то же самое, только вместо Mixin правим открытые исходники.
